# Matrix Helper Card (archived)

**This card is now built into [Matrix Helper](https://github.com/danielmsorensen/ha-matrix-helper)**,
starting with version 1.2.0. The integration serves the card itself and adds it to your
dashboard resources, so there's nothing separate to install, and the card updates with
the integration.

If you installed this card from HACS, remove it: in HACS, open **Matrix Helper Card**,
then ⋮ → **Remove**. Your existing cards keep working without changes.

The card's source and history now live in the integration's repository, under
[`frontend/`](https://github.com/danielmsorensen/ha-matrix-helper/tree/main/frontend).
Please open issues there.
